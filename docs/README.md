# 项目概览

项目以金融时序预测为主题，将行情数据处理、特征构造和模型实验放在一起，主要包括以下环节：

1. **构造特征**：从行情和订单簿数据中提取拍卖流动性、价格差异、买卖压力等信息，并利用算子扩展特征。
2. **检查因子**：通过单因子测试和泄漏检测示例，分析特征及其时间信息。
3. **训练模型**：组织训练、验证和测试窗口，尝试 GRU、LSTM、Transformer、TCN 和 MASTER 等模型。
4. **分析结果**：结合训练日志、模型权重和预测结果，比较不同模型与实验方案。

仓库包含 Python 脚本和实验 Notebook，适合作为竞赛复现与金融数据建模的研究材料。
